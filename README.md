# 🎓 BlockchainCert

BlockchainCert is a blockchain-based certificate validation system developed using Ethereum, Solidity, Ganache, Hardhat, Next.js, and Ethers.js.

The system ensures secure, tamper-proof, and verifiable academic certificates using blockchain technology and cryptographic hashing.

---

# 🚀 Features

## 👨‍💼 Admin Panel
- Register students
- Issue certificates
- Upload PDF certificates
- Generate SHA-256 hash
- Store certificate hash on blockchain
- View all records
- Revoke certificates

## 🎓 Student Portal
- Student login
- View issued certificates
- Download/view certificates

## 🔍 Verifier Portal
- Verify certificates using:
  - Uploaded PDF
  - Cryptographic hash
- Detect invalid/tampered certificates
